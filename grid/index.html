Graduate Experiments

← Graduate home · Research note: what the runs found

We tested the certifier on public agent benchmarks (τ²-bench retail, airline and telecom, public customer-service agent traces, and the start of AppWorld): a cheaper candidate shadows a large model's traffic, and the certifier says where, if anywhere, it can take over. The study closed on 23 October 2026. This page counts every run it made; the research note explains what they found.

Every verdict was pre-registered before its run: the claim, the metric and the pass bar were fixed first, and a run that failed or was stopped is counted, not dropped. Failed runs include test suites that caught a problem before paid work, which is their job. Stopped means no exit code was recorded: stopped by hand or by the watchdog.
